# Skill Nexis Week 2 Assignment

## Assignments
1. Contact Book using Dictionary
2. Word Counter from Text File
3. JSON File Reader

## Mini Project: Student Management System
The project stores student name, roll number and marks in a CSV file.

### Features
- Add student
- Display students
- Search student
- Update student
- Delete student
- Save changes permanently to `students.csv`

## How to Run
Install Python 3.

Run the mini project:
```bash
python student_management_system.py
```

Run the other assignments:
```bash
python contact_book.py
python word_counter.py
python json_reader.py
```

## Skill Gain
Data storage, file I/O, CSV/JSON handling, dictionaries and CRUD logic.
